# Waze User Behaviour Analysis Dashboard

## Project Overview
An Excel dashboard project to analyse user behaviour and compare retained and churned users of a navigation app.

## Objectives
- Analyse user retention and churn.
- Compare Android and iPhone users.
- Study sessions, drives, and navigation usage.
- Identify differences in user activity.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- KPI Cards
- GETPIVOTDATA
- Slicers

## Dashboard Features
- Total, retained, and churned users
- Average sessions and drives
- Device-wise user analysis
- Sessions vs. drives comparison
- Activity days vs. driving days
- Navigation usage analysis
- Interactive filters using slicers

## Key Insights
- Compare the behaviour of retained and churned users.
- Analyse differences in activity and driving frequency.
- Explore user engagement across device types.

## Skills Demonstrated
Data cleaning, data analysis, dashboard creation, data visualisation, and insight generation.
